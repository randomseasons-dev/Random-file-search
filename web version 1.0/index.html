Runs entirely in your browser. It crawls public, open-access sources that allow browser requests: it searches each source, then opens every matching item (archive items, records, repositories) and reads its full file list. General web pages and search engines block browser-only crawling (CORS), so they are not included. Best 50 matches are kept, re-sorted after every new find.
